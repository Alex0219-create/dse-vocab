# DSE Vocab V5.2（網站版）

V5.2 大版本更新：加入 Paper 3 聆聽綜合、AI 作文評分升級、語音評分、真題高頻詞、同義詞網絡、遊戲化、錯題弱點雷達、學習曲線、字體調整、PWA 安裝、SM-2 自適應等。

## V5.2 更新內容

### 🎧 Paper 3 聆聽及綜合能力（全新模組）
- 聆聽詞彙：揀分類聽 TTS 發音（英文 + 中文）
- 聆聽理解：2 篇模擬廣播（Open Day / 環保週），聽完答題即時評分
- Data File 綜合：模擬 Paper 3 整合題型（錄音 + 資料檔同步作答）
- Paper 3 佔 DSE 英文科 30%，係最大比重

### 🎤 口語發音評分（全新）
- 用咪高峰讀詞彙，瀏覽器語音識別即時比對，Levenshtein 距離計分（0-100）
- 聽正確發音 → 朗讀 → 睇分數同評語

### 🤖 AI 作文評分升級
- 新增「5** 示範文＋結構分析」：完整示範文 + 五段式結構拆解 + 5** 關鍵要素
- 保留離線規則評分 + LLM API 深度評分

### 📌 DSE 真題高頻詞
- 內置 60 個真題高頻詞，詞庫瀏覽時顯示「📌 DSE 真題高頻詞」標籤

### 🔗 同義詞網絡
- 內置 20 組常用詞同義詞組（important→crucial/essential/vital…）
- 詞庫詳情頁顯示同義詞，詞庫有收錄嘅可以直接點擊跳轉

### 🏆 遊戲化
- 連續打卡 Streak（3/7/30 日成就徽章）
- 首頁成就列 + 解鎖通知

### 🎯 錯題弱點雷達
- 統計錯題按星級/詞性/分類分佈，一眼睇到弱點

### 📈 學習曲線
- 統計頁新增近 30 日每日學習量曲線

### 🔤 字體大小調整
- 設定頁 A−/A+ 調整字體（12-22px）

### 📱 PWA 安裝（新增）
- 支援「加到主螢幕」、離線使用（manifest.json + sw.js + icon.svg）
- 部署到 GitHub Pages 後手機 Chrome 可直接安裝

### 🧠 SM-2 自適應
- 錯詞比例高嘅學生自動放慢複習節奏（先打穩基礎），正常學生維持原速

## 使用方式
1. 上傳以下檔案到 GitHub Pages（alex0219-create/dse-vocab main 分支）：
   - index.html
   - dse_vocab_data.js
   - manifest.json
   - sw.js
   - icon.svg
2. 等 1-2 分鐘，手機開 https://alex0219-create.github.io/dse-vocab/（加 ?v=52 或無痕防快取）
3. 想裝做 App：Chrome 選單 →「加到主螢幕」

## 本地使用
- index.html + dse_vocab_data.js 放埋同一資料夾，用瀏覽器打開 index.html 即可
- 舊數據（V5.1.x）自動遷移，唔會丟失
